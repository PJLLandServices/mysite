# Blog Image Shot List — Picture Spots to Fill

This is the photo checklist for the five curated blog posts. Each post now has
labelled **picture spots** built into the page. Until a photo is added, each spot
shows a dashed placeholder box on the page describing the shot and naming the file.

## How to add a photo (no code needed)

1. Take/pick the photo for a spot below.
2. Name the file **exactly** as listed (lowercase, keep the hyphens and the `.jpg`).
3. Drop it into the repo root — the same folder as the blog `.html` files.
4. That's it. The placeholder box is replaced by your photo automatically the next
   time the page loads. No HTML editing required.

**Format:** landscape shots ≈ 1600×1000 px (3:2-ish), phone/portrait shots ≈ 1080×1920 px.
JPG, reasonably high quality — the site's build step can generate smaller `@800w`/`@1280w`
versions later if we want responsive loading.

**Reuse is fine:** where an existing site photo already fits, I've noted it. You can
either copy that file to the new name, or tell me and I'll point the spot at the
existing file directly.
