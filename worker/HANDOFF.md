## What This Project Is

PJL Land Services is a sprinkler/irrigation repair and installation business in the Greater Toronto Area (Ontario, Canada). The owner, Patrick, has a website at `www.pjllandservices.com` with a live "AI Sprinkler Diagnosis" tool at `diagnose.html`.

The tool is a chat interface where homeowners describe their sprinkler problem in plain English, and an AI persona (Patrick) responds with diagnoses, self-fix steps, and quotes — eventually capturing leads that want to book service calls.

```

      ↓

                repo (NOT GitHub Pages — that was the original plan,

      ↓
js/chat-widget.js
      - POSTs each chat turn to the Cloudflare Worker (below)
      - POSTs captured leads/quotes to same-origin /api/quotes
        (server/server.js, validated against pricing.json in
        server/lib/quotes.js)
      - POSTs full transcripts to same-origin /api/chat-transcripts
      ↓
Cloudflare Worker (https://jolly-meadow-6c29.patrick-812.workers.dev/)
      - this repo's worker.js — NOT deployed via CI/git, hand-pasted into
        the Cloudflare dashboard (see "Deployment Steps" below)
      - its SYSTEM_PROMPT is generated, not hand-typed: worker/rebuild.mjs
        reads worker/system_prompt.md (voice/rules/flow text with {{key}}
        pricing placeholders) + pricing.json (the actual numbers) and
        splices the substituted result into worker.js. Fixed 2026-09-20 —
        this build script already existed in the repo but nothing had
        ever actually run it, so worker.js had drifted to hardcoded
        literal numbers that no longer matched pricing.json by the time
        this was caught; see PJL-43 in Linear.
      - adds system prompt + API key, calls Anthropic API
      ↓
Anthropic API returns Claude response
      ↓
Worker returns { reply, usage } to chat-widget.js
      ↓
chat-widget.js renders Patrick's reply in chat UI
```

**Key components:**
- **Frontend:** `diagnose.html` + `js/chat-widget.js` + `css/chat-widget.css` — served on the live site by Render, linked from 25+ pages (homepage, FAQ, pricing, sprinkler-repair, sprinkler-systems, most blog posts)
- **Chat backend:** Cloudflare Worker — `worker.js` — holds the system prompt (generated by `rebuild.mjs` from `pricing.json`, not hand-typed) and the `ANTHROPIC_API_KEY` secret
- **Lead/quote backend:** `server/server.js` (`/api/quotes`, `/api/chat-transcripts`) — same Render app that serves the rest of the site, validates quotes against `pricing.json`
- **AI:** Anthropic Claude (model: `claude-sonnet-4-5`) accessed via API

Separately, `cloudflare/updating-page/worker.js` is a **different, unrelated** Worker — it only masks Render's brief 502 during deploys with a branded "we're updating" page. Don't confuse the two.

## Critical Pricing & Policy Reference

**Prices are no longer hand-typed into the system prompt (fixed 2026-09-20).** `pricing.json` at the repo root is the single source of truth for every dollar figure PJL quotes anywhere on the site. To change a price the chat bot quotes:

1. Edit the number in `pricing.json`.
2. Run `node worker/rebuild.mjs` from the repo root — it reads `worker/system_prompt.md`'s `{{key}}` placeholders, resolves them against `pricing.json`, and splices the result into `worker.js`'s `SYSTEM_PROMPT` constant.
3. Redeploy `worker.js` to Cloudflare (see "Deployment Steps" below) — this is still a manual step.

(The two numbers below are stale as of this doc's original writing and are left only to show the *shape* of the pricing — always check `pricing.json` for the real numbers, never this table.)

Example shape (see `pricing.json` for actual current values): service call flat fee + hourly labour rate; the AI-intake correct-diagnosis bonus (1 hour of repair labour free — PJL's only discount); per-repair flat/per-unit prices for heads, manifolds, valves, wire runs, pipe breaks; zone-tiered controller and new-install pricing; zone-tiered spring/fall seasonal pricing (residential + commercial).

**Critical service philosophy — The Whole Manifold Rule:** When ANY valve in a box fails, PJL replaces the entire manifold AND all valves in that box together — never single-valve repair. Customer pays manifold price + per-valve price for every valve in the box. (This rule and its formula are documented in `pricing.json`'s `rules.whole_manifold_rule` and mirrored in `worker.js`'s system prompt.)

**Refer-out (PJL does NOT service):**
- Backflow preventers → certified backflow specialist
- Inside-house plumbing → licensed plumber
- Utility-side leaks (between meter and house shutoff) → municipal water dept

## Deployment Steps

### Step 1: Deploy worker.js to Cloudflare

The Cloudflare Worker holds the system prompt and the Anthropic API key. **If you changed `pricing.json` or `worker/system_prompt.md`, run `node worker/rebuild.mjs` from the repo root first** — it regenerates `worker.js`'s `SYSTEM_PROMPT` constant from those two files. Skipping this step means you'll deploy whatever `worker.js` last had baked in, which may not match your edits.

Then, to update the live Worker:

**Option A — Manual (current setup):**
1. Open https://dash.cloudflare.com → Workers & Pages → `jolly-meadow-6c29`
2. Click "Edit code"
3. Select all existing code and delete
4. Copy the entire contents of `worker.js` from this repo, paste into the editor
5. Click "Save and Deploy"
6. Verify deployment with the built-in HTTP test panel:
   - Method: POST
   - URL: (default, the Worker URL)
   - Headers: `Content-Type: application/json`
   - Body:
     ```json
     {"messages":[{"role":"user","content":"Say hello briefly"}]}
     ```
   - Click send. Should return 200 with a `reply` field containing Patrick's hello.

**Option B — Wrangler CLI (recommended for ongoing work):**
```bash
# One-time setup
npm install -g wrangler
wrangler login

# To deploy
wrangler deploy worker.js --name jolly-meadow-6c29

# To set/update the secret (ONLY if regenerating the API key):
wrangler secret put ANTHROPIC_API_KEY --name jolly-meadow-6c29
```

⚠️ **Do not regenerate the API key unless necessary.** It's already configured as a Cloudflare secret. Regenerating means going through the Anthropic console + redeploying the secret.

## How To Iterate On Patrick's Voice

If responses from the AI feel off, the fix is almost always to edit `worker/system_prompt.md` — never `worker.js`'s `SYSTEM_PROMPT` constant directly, since that's now generated and your hand-edit would be overwritten (or just drift again) the next time someone runs the rebuild.

Workflow:
1. Edit `worker/system_prompt.md` to fix whatever's off (tone, missing trade detail, pricing logic, etc.). Reference a price as `{{pricing_json_key}}`, never a literal dollar figure — see the existing placeholders for the pattern, including the `{{a + b}}` sum syntax for a derived total like "parts + one hour of labour."
2. Run `node worker/rebuild.mjs` from the repo root to regenerate `worker.js`'s `SYSTEM_PROMPT`.
3. Redeploy `worker.js` to Cloudflare (Step 1 of Deployment).
4. Test the live chat tool to verify the change.

Common edit reasons:
- Patrick wants to update a price → edit `pricing.json`, not `system_prompt.md` (the placeholders there already point at the right keys) — then still run the rebuild + redeploy above.
- Customer-facing diagnosis voice feels too robotic / too markdown-heavy → tighten the "HOW YOU TALK" section
- New trade knowledge to teach Patrick → add to "SELF-FIX PLAYBOOKS" or "DEAD-END FOLLOW-UPS"

## Testing Scenarios

After deploying, test these scenarios in order to confirm Patrick is working correctly:

1. **Bleeder screw fix:** "good morning, water is constantly flowing from one of my sprinkler zones, doesn't stop even when system is off"
   - Expected: Empathy + bleeder screw + solenoid explanation + "want to try yourself or send a tech?" question.

2. **Self-fix follow-up:** Reply "I tried the screws and solenoids, water still flowing from zone 3"
   - Expected: One question about whether multiple zones or just one, then quote the 3-valve manifold rebuild total from `pricing.json`'s `manifold_examples` (currently $454.85 — check `pricing.json` for the live figure, don't hardcode this in a test script either).

3. **Booking trigger:** Reply "yeah send a tech"
   - Expected: Reply ends with `[SHOW_BOOKING_FORM]` token (invisible to customer), inline form bubble appears in chat.

4. **Refer-out:** "do you do backflow testing?"
   - Expected: Polite refer-out to a backflow specialist.

5. **Dead system:** "my whole sprinkler system won't turn on at all"
   - Expected: Empathy + electrical-basics diagnosis + breaker/GFCI/transformer self-check offer.

6. **Geyser:** "one of my sprinklers is shooting straight up like a fountain"
   - Expected: Diagnose snapped head + offer self-check OR direct quote at $95 + $68/head.

If any of these flows produce the wrong tone, wrong pricing, or wrong diagnosis, edit the system prompt accordingly.
